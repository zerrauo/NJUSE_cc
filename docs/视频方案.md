## 口播稿（全文约 450 字，按 4–4.5 字/秒语速）

**片段 1（开场，10s）**

> 大家好，这是我独立实现的编程智能体。给它一个任务，它能自己读文件、改代码、跑命令、修错误，直到任务完成。

**片段 2（主演示，45s）**

> 先看核心演示，任务是一个有 bug 的待办应用：编号从零开始，还缺完成标记功能。我用计划模式启动，模型先给出执行计划，确认后才动手。执行中它先列出目录、读取源码和测试，再用精确匹配的方式做局部编辑，而不是整体重写文件。改完后它自己装依赖、跑测试，命令不存在就换成 python3 重试。五个测试全部通过，还顺手修掉了删除后编号重复的隐患。

**片段 3（危险命令，20s）**

> 再看安全设计。它想用 rm -rf 删目录，被黑名单拦下，必须先经用户确认。我拒绝后，它没有卡住，而是收到反馈、自动改用更安全的删除方式：先删文件、再删空目录，任务照样完成。

**片段 4（只读模式，17s）**

> 这是只读模式：写文件的工具根本不发给模型，想改也改不了。让它修 bug，它会复现问题、给出建议，但明确表示需要可写权限。只读是硬保证，不是靠自觉。

**片段 5（设计讲解，28s）**

> 最后讲实现。整个 agent 就是这样一个循环：调用模型，解析它返回的工具调用，本地执行，把结果喂回去，直到模型不再调用工具。对话管理、工具定义、输出解析、终止条件、错误处理，全部自己编写，没用任何 agent 框架。上下文太长时，旧历史自动压缩成摘要；同一调用连续重复三次会被警告打断。全部逻辑有二十一个测试守护。谢谢观看。

## 录制操作步骤（QuickTime，Mac 自带）

1. **准备**：终端进入项目目录；关掉多余窗口；**千万不要打开 .env 文件**（API key 不能出现在视频里）。
2. **开始录屏**：⌘⇧5 → 选"录制整个屏幕"（或框选终端区域）→ 在"选项"里勾选内建麦克风。
3. **逐段录**（每段之间停止再开始，方便剪辑）：
   - 片段 1：敲 `ls` 展示项目文件；
   - 片段 2：跑 `./demo/bugfix.sh`，计划出现后输 `y`（实际耗时约 1–2 分钟，后期会加速，录得慢没关系）；
   - 片段 3：跑 `./demo/danger.sh`，出现"是否执行？"时输 `n`；
   - 片段 4：跑只读分析任务；
   - 片段 5：打开 `agent/loop.py` 慢慢滚动。
4. **口播**：可以边录边念口播稿；**也可以不出声录画面，之后单独用手机语音备忘录念一遍口播稿**（推荐：念错了可以重录，画面也不受干扰）。
5. **导出/剪辑**：把原始片段和口播录音交给 Claude 用 ffmpeg 拼接、加速、配音、导出 mp4；或自己用 iMovie 处理。
